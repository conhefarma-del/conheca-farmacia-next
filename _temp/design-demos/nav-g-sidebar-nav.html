💡 Quando usar esta variante
Melhor para sites com muitas secções permanentes (8+) que não cabem no header. Elimina o problema de "header cheio" definitivamente — a sidebar cresce verticalmente sem ocupar header. Inspiração: Notion, Linear, GitBook. A sidebar colapsável dá flexibilidade: expanded para desktop, collapsed para screens médios, drawer para mobile. Ideal se o site vai crescer muito (ex: +3 secções nos próximos meses).
