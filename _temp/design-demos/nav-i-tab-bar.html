Variante I · Tab Bar Inferior (estilo app nativa)

Abandona o header como destino principal. Em vez disso, usa uma tab bar fixa no fundo — como Instagram, WhatsApp, PedidosJá. Header fica super compacto (logo + ícones). Tab central "Protocolos" com FAB (floating action button) para a acção principal. Ideal para mobile-first.

💡 Quando usar esta variante
Escolhe esta se Conheça Farmácia é predominantemente consumida em mobile (profissionais de saúde no balcão, consulta, hospital). A tab bar inferior é a interface mais rápida para thumb — os 4 destros principais sempre acessíveis com uma mão. O FAB central "Protocolos" torna a acção mais importante (guia clínico no momento da consulta) sempre a um toque. Desktop converte-se automaticamente para header limpo + mesma tab bar para consistência. Melhor para apps/progressive web apps.
