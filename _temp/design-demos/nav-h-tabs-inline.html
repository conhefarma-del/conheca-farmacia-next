Variante H · Tabs Inline (sub-nav independente)

Header separa-se em 2 níveis: (1) header fixo com logo + search, (2) sub-nav com tabs horizontais inline. No mobile, tabs viram scroll horizontal pill-style + hamburger para menu completo. Sem dropdowns — todas as páginas são tabs.

Desktop · Sub-nav com tabs
Header simples (logo+lupa). Sub-nav logo abaixo com todas as secções como tabs (Início, Ferramentas, Guias, Artigos, Protocolos, Eventos, Lives, Directório). Active tab com underline accent. Scroll horizontal se necessário. Sub-itens (Ferramentas→Interacções) aparecem como dropdown ou como segunda linha de tabs aninhados.

💡 Quando usar esta variante
Escolhe esta se queres que todas as secções sejam descobertas sem cliques extra. As tabs inline Communication "tudo o que há aqui" de imediato. Funciona bem para Conheça Farmácia se tens poucas subpáginas por categoria (≤3). No mobile, scroll horizontal de pills é padrão iOS/Android. Acede a subpáginas via drawer ou inline dropdown nos pills com ▾.
