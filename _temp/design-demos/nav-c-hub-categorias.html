Variante C · Hub com Pills

Transformar header num "hub" com pills horizontais (como o filters-bar) para categorias principais. Subpáginas aparecem em dropdown compacto com ícone + descrição. Resultado: mais horizontal, menos vertical.

Desktop · Pills + dropdown compacto
Header vira hub: Início (pill filled) + Ferramentas/Guias/Artigos/Directório (pills outline com count badge). Hover/click mostra dropdown com ícone 28px + nome + micro-descrição. Menos intrusivo que mega menu.

💡 Quando usar esta variante
Escolhe esta se queres um header limpo e horizontal, mais parecido com apps modernos (Linear, Notion). Os pills comunicam directamente "quantas subpáginas tem aqui" sem ocupar muito espaço. Melhor para até 5 categorias principais. O dropdown compacto é suficiente para 3-4 itens com ícones. No mobile, mantém o drawer que os usuários já conhecem.
