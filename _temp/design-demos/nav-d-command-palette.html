Variante D · Command Palette (⌘K)

Header minimalista. Toda a navegação concentrada numa palette tipo Spotlight/Vercel/Raycast. ⌘K ou clique na barra de pesquisa para abrir. Resultados agrupados por categoria com ícone + descrição + shortcut. Adeus dropdowns, olá velocidade.

Desktop · ⌘K palette
Header com logo + search bar como elemento principal. Clica ou ⌘K → palette centralized com resultados agrupados (Navegação / Ferramentas / Conteúdos). Ideal para power users.

💡 Quando usar esta variante
Melhor se a tua audiência é tech-savvy (profissionais de saúde jovens, estudantes) e o site tem muitas páginas (20+). Combina com plataformas que já usam command palette (Vercel, Linear, Notion). Para Conheça Farmácia, funciona se o público-alvo for principalmente estudantes/internos/supervisores digitais. Pode ser combinado com Variante B (hub com pills) — pills visíveis + palette como atalho power-user.
